FRAME INBOX — sideloaded copy
=============================

This is the portable bundle: the app runs from this folder, and keeps its data in
~/.local/share/frame-inbox/.

Run it with ./frame-inbox (or let FrameDrop/Steam launch it for you).
On first run it starts a small page on port 8765 and shows a control panel.

On the phone: open http://<headset-ip>:8765 and add it to your home screen.
Find the address in the panel — tap the line under the title to select it.

It is a desktop utility, so it is happiest in Desktop Mode. Nothing is installed
system-wide and no root is needed; delete this folder to remove the app, and
~/.local/share/frame-inbox/ to remove its data.

Source and docs: https://github.com/variablefate/frame-inbox
